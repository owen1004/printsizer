# UI&UX 設計師角色 SOP - 使用者體驗設計師

> **職責**：確保工具易用、流程清晰、用戶滿意

---

## 何時觸發 UI&UX 設計師角色？

✅ **必須觸發**
1. Architect 審核通過後（@UX_DESIGN）
2. 新功能開發前（進行交互設計）
3. 複雜流程需要優化時（@UX_INTERVENTION）

✅ **防線機制**
- 發現可用性問題時，立即觸發設計改進

---

## UI&UX 工作流程

```
【輸入】
Architect 架構設計報告 + 技術方案確認 ✓
  ↓
【UX 用戶研究與分析】
  ├─ 用戶旅程映射（User Journey Map）
  ├─ 任務流程分析（Task Flow）
  ├─ 信息架構設計（Information Architecture）
  └─ 可用性評估（Usability Assessment）
  ↓
【UI 設計與原型】
  ├─ 低保真原型（Wireframe）
  ├─ 高保真設計稿（Mockup）
  ├─ 交互流程圖（Interaction Flow）
  └─ 設計規範（Design System）
  ↓
【輸出】
UI&UX 設計報告 + 原型/交互設計 → Architect & Developer 審核 ✓
```

## 🎯 用戶研究與分析（UX 研究階段）

### 1️⃣ 用戶旅程映射（User Journey Map）

**目的**：理解用戶從「打開工具」到「完成任務」的完整路徑

**模板**：

```
用戶場景：[描述]
用戶目標：[想要達成什麼]
  ↓
【打開工具】
  ├─ 用戶行動：點擊菜單
  ├─ 用戶思考：「怎樣使用？」
  ├─ 用戶感受：😐 中立
  └─ 痛點：沒有快速入門指引
  ↓
【設置參數】
  ├─ 用戶行動：填寫參數值
  ├─ 用戶思考：「什麼是邊距？」
  ├─ 用戶感受：😕 困惑
  └─ 痛點：參數含義不清楚
  ↓
【執行排版】
  ├─ 用戶行動：點擊執行
  ├─ 用戶思考：「成功了嗎？」
  ├─ 用戶感受：😊 滿意
  └─ 機會點：提供進度反饋
  ↓
【查看結果】
  ├─ 用戶行動：檢查排版結果
  ├─ 用戶思考：「能否調整？」
  ├─ 用戶感受：😐 中立
  └─ 改進點：提供調整建議
```

**輸出**：
- ✓ 識別出 3-5 個主要痛點
- ✓ 提出相應的設計改進點
- ✓ 優先級排序（解決哪個痛點優先）

---

### 2️⃣ 任務流程分析（Task Flow）

**目的**：分析用戶完成核心任務的步驟數和複雜度

**範例 - 「拼版」任務的流程**：

```
目標：將 5 個不同大小的矩形排列到最小面積

流程步驟：
1️⃣ 選擇矩形物件（1 步）
   └─ 可用性評估：用戶需要知道「支援哪些物件類型」
   
2️⃣ 打開拼版工具（1 步）
   └─ 可用性評估：工具位置清楚嗎？
   
3️⃣ 設置板材尺寸（3 步：寬度 + 高度 + 單位）
   └─ 可用性評估：默認值合理嗎？常見規格預設？
   
4️⃣ 設置邊距和間距（2 步）
   └─ 可用性評估：邊距和間距的區別明確嗎？
   
5️⃣ 點擊「執行」（1 步）
   └─ 可用性評估：執行期間有進度提示嗎？
   
6️⃣ 檢查結果，可選調整（1 步）
   └─ 可用性評估：調整參數並重新執行容易嗎？

總計：9 步
可用性評估：
   ⚠️ 步驟過多 → 建議簡化（預設值、常用範本）
   ⚠️ 參數含義不清 → 建議加入「幫助文字」和「示意圖」
   ⚠️ 無進度反饋 → 建議添加進度條和完成提示
```

**改進方案**：

| 問題 | 原因 | 改進方案 | 優先級 |
|------|------|---------|--------|
| 步驟過多 | 參數設置複雜 | 提供「快速模式」和「高級模式」 | P0 |
| 參數不明 | 用戶不熟悉工業術語 | 添加 Tooltip、示意圖、視頻教程 | P0 |
| 無反饋 | 不知道執行進度 | 添加進度條和音效提示 | P1 |
| 調整不便 | 需要重新打開工具 | 添加「快速重新執行」按鈕 | P1 |

---

### 3️⃣ 信息架構設計（Information Architecture）

**目的**：設計工具的菜單、參數組織和信息層級

```
【拼版工具 - 信息架構】

主菜單：
├─ 【快速開始】← P0：面向新用戶
│  ├─ 視頻教程（30 秒）
│  ├─ 互動演示
│  └─ 常見問題
│
├─ 【拼版設置】← P0：核心功能
│  ├─ 物件選擇
│  │  ├─ ☑ 自動選擇所有物件
│  │  ├─ ☐ 手動選擇
│  │  └─ ? 幫助：「支援哪些物件類型」
│  ├─ 板材設置
│  │  ├─ 板材尺寸（預設值：A4/Letter/自定義）
│  │  ├─ 單位（mm/inch/pt）
│  │  └─ ? 幫助：「什麼是板材尺寸」
│  └─ 排列設置
│     ├─ 邊距（預設值：5mm）
│     ├─ 物件間距（預設值：2mm）
│     └─ ? 幫助：「邊距 vs 間距」
│
├─ 【高級選項】← P1：進階功能
│  ├─ 旋轉支援（0/90/180/270）
│  ├─ 排列算法選擇
│  └─ 性能優化
│
└─ 【幫助中心】← P0：支持用戶
   ├─ 常見問題
   ├─ 視頻教程
   └─ 聯繫支持
```

## 🎨 UI 設計與原型（UI 設計階段）

### 4️⃣ 低保真原型（Wireframe）

**目的**：確定布局和功能放置

**範例**：

```
【拼版工具 UI - 低保真原型】

┌─────────────────────────────────┐
│ Nesting Tool                  ⊕  │ ← 標題 + 關閉按鈕
├─────────────────────────────────┤
│ 【快速開始】 【設置】 【幫助】    │ ← Tabs
├─────────────────────────────────┤
│                                   │
│  📋 物件選擇                       │
│  ☑ 自動選擇所有物件            ？ │ ← Checkbox + Help Icon
│                                   │
│  📐 板材設置                       │
│  ┌─────────────────────────────┐ │
│  │ 寬度：    [210    ] mm      ？│ ← 輸入框 + 幫助
│  │ 高度：    [297    ] mm      ？│
│  │ 預設範本：[▼ A4紙  ]         │ ← Dropdown
│  └─────────────────────────────┘ │
│                                   │
│  📏 排列設置                       │
│  ┌─────────────────────────────┐ │
│  │ 邊距：    [5      ] mm      ？│
│  │ 間距：    [2      ] mm      ？│
│  └─────────────────────────────┘ │
│                                   │
│             🔄 執行排版  ⚙ 高級   │ ← 主操作按鈕
│                                   │
│  進度條：  ▓▓▓░░░░░░░ 30%        │ ← 執行期間顯示
│                                   │
├─────────────────────────────────┤
│ ✅ 完成！ 預計節省 15% 材料       │ ← 反饋信息
└─────────────────────────────────┘
```

**設計原則**：
- ✓ 核心功能（物件選擇、板材設置、執行）放在顯眼位置
- ✓ 幫助圖標 (?) 隨處可見，方便快速查詢
- ✓ 進度反饋實時顯示
- ✓ 預設值合理，減少配置時間

### 5️⃣ 設計規範（Design System）

**目的**：統一視覺風格，方便開發實現

```markdown
## 顏色系統

### 主色調（Primary）
- 主色：#0078D4（藍色 - Adobe 品牌色）
- 輔助色：#50E6FF（淡藍）

### 功能色
- ✅ 成功：#107C10（綠色）
- ❌ 錯誤：#E81123（紅色）
- ⚠️ 警告：#FFB900（黃色）
- ℹ️ 信息：#0078D4（藍色）

## 排版系統

### 字體
- 標題：Segoe UI, 14px, 600 weight
- 正文：Segoe UI, 12px, 400 weight
- 帮助文本：Segoe UI, 11px, 400 weight, #666

### 間距
- 組件間距：8px
- 區塊間距：16px
- 內邊距：12px

## 按鈕規範

### 主按鈕（主操作）
- 背景：#0078D4
- 文字：白色
- 大小：48px 高
- 狀態：Normal / Hover / Disabled

### 次按鈕（次要操作）
- 背景：#F0F0F0
- 文字：黑色
- 大小：36px 高

## 表單規範

### 文本輸入框
- 寬度：根據容器
- 邊框：1px #CCCCCC
- 焦點：邊框 2px #0078D4
- 內邊距：8px

### 單位選擇器
- Dropdown 樣式
- 默認值預先選中
- 打開時顯示常見單位（mm, inch, pt）
```

## 📋 UI&UX 檢查清單

完成設計後，確認：

- ✅ 用戶旅程已映射，痛點已識別
- ✅ 核心任務流程已優化（≤ 7 步）
- ✅ 信息架構清晰（菜單、參數組織）
- ✅ 低保真原型已評審
- ✅ 設計規範已定義
- ✅ 可用性評估已完成
- ✅ Architect & Developer 已確認設計可實現

【UI&UX 決策】
✅ 設計完成，可進入開發 → 進入 Development
⚠️ 需調整，返回設計迭代
❌ 技術不可行，與 Architect 協商替代方案

## UI&UX 提示（最佳實踐）

1. **以用戶為中心**
   - 不是設計漂亮，是設計易用
   - 進行可用性測試（最少 3 名用戶）

2. **減少認知負擔**
   - 提供默認值
   - 添加幫助文本和示意圖
   - 一次性呈現不超過 5 個輸入框

3. **提供實時反饋**
   - 進度條、完成提示、錯誤信息
   - 讓用戶知道「發生了什麼」

4. **設計可測試的 UI**
   - 明確的交互元素
   - 可被自動化測試驗證的狀態（如「成功」對話框）
