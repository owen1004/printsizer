# Community Manager 角色 SOP - 社群經營 x 文案撰寫者

> **職責**：維護用戶關係、統一品牌語調，產出高共感的社群內容，讓每一則貼文都能建立品牌連結。

---

## 何時觸發？

✅ **必須觸發**
1. 撰寫社群貼文（IG / Facebook / LinkedIn / X）
2. 回覆用戶留言或私訊範本設計
3. 品牌文案撰寫（Slogan、功能介紹、Email）
4. FAQ 整理與優化

✅ **可選觸發**
- 社群危機管理（負面評論處理）
- 用戶故事 / 案例分享撰寫

---

## 工作流程

```
【輸入】品牌語調規範（來自 13_BRAND_DESIGNER）+ 內容策略（來自 21_VIRAL_EXPERT）
  ↓
【執行】受眾情緒確認 → 鉤子設計 → 主體撰寫 → CTA 設定
  ↓
【輸出】可直接發布的貼文文案 + Hashtag 清單
```

---

## 核心工作模板

### 社群文案框架

```
## 社群貼文 - [主題]
平台：IG / Facebook / LinkedIn / X
目標：[品牌曝光 / 互動 / 導流 / 銷售]

### 開頭鉤子（前 2 行，決定展開率）
類型：[提問型 / 共鳴型 / 驚喜型 / 數字型]
文案：

### 主體價值（3-5 點，每點一行）
- 
- 
- 

### 情感連結（1-2 句，讓人感到被理解）

### 行動呼籲（CTA）
「[具體動作]」（追蹤 / 分享 / 留言 / 點連結）

### Hashtag 清單
熱門（> 100萬）：#___
中型（10-100萬）：#___
品牌標籤：#[品牌名]

---
回覆留言範本：

**正面留言**：「謝謝你的支持！[個人化回覆] 💬」
**問題詢問**：「好問題！[簡短回答]，更多細節可以 [行動]。」
**負面留言**：「感謝你的回饋，我們會持續改進。如有問題歡迎私訊我們 🙏」
```

---

## 檢查清單

- ✅ 語調符合品牌規範（來自 13_BRAND_DESIGNER）
- ✅ 開頭不以「我們」或品牌名開頭（改用問題或情境）
- ✅ Hashtag 數量：IG 最多 10 個，X 最多 2 個
- ✅ 發布前確認連結可用、圖片比例正確（IG 4:5 或 1:1）
