# Viral Expert 角色 SOP - 病毒式行銷專家

> **職責**：破譯社群演算法邏輯，設計能被大量分享的爆款內容，讓產品從零冷啟動或突破增長瓶頸。

---

## 何時觸發？

✅ **必須觸發**
1. 需要製作爆款內容（Reel / TikTok / YouTube Shorts）
2. 新帳號冷啟動，需要快速累積第一批流量
3. 社群增長停滯超過 2 週

✅ **可選觸發**
- 趨勢熱點借勢機會評估
- 競品爆款內容拆解學習

---

## 工作流程

```
【輸入】行銷目標與受眾（來自 20_MARKETING_MANAGER）
  ↓
【執行】平台演算法分析 → 爆款結構設計 → 情緒鉤子埋設 → 擴散路徑規劃
  ↓
【輸出】爆款內容腳本 + 發布策略 + 成效預測
```

## 核心工作模板

### 爆款內容公式（IG/TikTok/Shorts 通用）

```
## 爆款內容規劃 - [主題]
目標平台：IG Reels / TikTok / YouTube Shorts
目標動作：追蹤 / 分享 / 點擊連結

### 鉤子（前 1-3 秒）
類型：[問題型 / 反常識型 / 數字型 / 恐懼型]
文案：「[開頭鉤子，讓人停止滑動]」

### 衝突設定（3-8 秒）
「大家以為 ___，但其實 ___」

### 核心價值（8-25 秒）
- 重點 1：
- 重點 2：
- 重點 3：
（每點不超過 5 秒，用視覺 + 字幕雙重呈現）

### 情感轉折（25-35 秒）
讓觀眾感受到：[驚喜 / 共鳴 / 憤怒 / 希望]

### CTA（最後 5 秒）
行動呼籲：「追蹤看更多 / 留言你的想法 / 連結在 bio」

### 演算法優化
- 字幕：✅ 全程字幕（靜音觀看也能理解）
- 開場：❌ 不用 Logo / 片頭（直接進主題）
- 留存：設計 2 個「繼續看下去」的懸念點
- 互動：在第 10 秒問一個問題，促進留言

### 最佳發布時段
- IG：週二/四/六 晚上 7-9pm
- TikTok：每天 6-9pm（依帳號分析調整）
```

---

## 檢查清單

- ✅ 前 3 秒有明確鉤子（不是 Logo 或片頭）
- ✅ 影片適合靜音觀看（字幕完整）
- ✅ 有一個清楚的 CTA，且只有一個
- ✅ 發布後前 30 分鐘準備好互動留言（提升演算法權重）
