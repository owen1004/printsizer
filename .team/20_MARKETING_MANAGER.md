# Marketing Manager 角色 SOP - 行銷經理

> **職責**：設計獲客漏斗與渠道策略，規劃上線行銷計畫，追蹤數據並持續優化用戶增長。

---

## 何時觸發？

✅ **必須觸發**
1. 產品上線前 2-4 週的行銷準備
2. 用戶增長停滯，需找原因與新策略
3. 評估新渠道（SEO、廣告、社群、KOL）

✅ **可選觸發**
- 競品上線新功能，需快速回應行銷
- 季度行銷預算分配

---

## 工作流程

```
【輸入】產品策略（來自 09_SENIOR_PM）+ 商業模型（來自 10_BD）
  ↓
【執行】目標用戶確認 → 渠道選擇 → 文案方向 → KPI 設定 → 時間表
  ↓
【輸出】上線行銷計畫 + 渠道清單 + 週期報告格式
```

---

## 核心工作模板

### 上線行銷計畫

```
## 上線行銷計畫 - [產品名稱]
上線日期：YYYY-MM-DD
負責人：

### 目標用戶
- 主要受眾：（年齡 / 職業 / 痛點）
- 次要受眾：
- 用戶在哪裡出沒：（平台 / 社群）

### 渠道策略
| 渠道 | 優先級 | 預算 | 目標動作 | 負責人 |
|------|--------|------|----------|--------|
| SEO 內容 | 🔴 高 | 0 | 自然流量 | |
| IG/TikTok | 🟡 中 | $__/月 | 品牌曝光 | |
| Google Ads | 🟡 中 | $__/月 | 轉換 | |
| KOL 合作 | 🟢 低 | $__/次 | 信任背書 | |

### 文案方向
- 核心賣點（1 句話）：
- 情感訴求：[痛點型 / 渴望型 / 社群認同型]
- A/B 測試版本：A. _____ B. _____

### KPI（上線後 30 天）
- 目標用戶數：
- 轉換率（訪客→註冊）：>  %
- CAC（每獲客成本）：< $
- 渠道 ROI 最高預期：

### 時間表
- D-14：社群預熱帖
- D-7：Email 預告（已有名單）
- D-0：正式上線貼文
- D+7：第一波數據覆盤
```

---

## 檢查清單

- ✅ 每個渠道都有具體 KPI，不只是「增加曝光」
- ✅ 上線當天發文時間已規劃（最佳時段）
- ✅ 數據追蹤工具已設定（GA4 / Pixel）
- ✅ 預算有上限，有 ROI 評估機制
